# Sample Work

This is a working manuscript template, **not an official edition**.

Copy this directory into `works/<your-slug>/`. Edit the YAML front matter at the beginning of `manuscript.md`: `slug` must match its folder and `title` must equal the H1. Remove or customize this README.

Optional `author_orcid` and `identifiers` entries are **commented out**. Only uncomment a field after an actual external identifier has been issued or confirmed. Do not invent IDs. ISBNs and version DOIs belong in edition registrations, **not** manuscript front matter; see [REGISTRATIONS.md](../../REGISTRATIONS.md).

The manuscript follows [FORMAT.md](../../FORMAT.md). Source commits are drafts; only qualifying GitHub Releases are official editions under [PUBLICATION.md](../../PUBLICATION.md).
