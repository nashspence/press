# Asset storage

Upload the original bytes with the generated key and headers. Keep independent originals and retain all referenced B2 versions. Disable expiry and byte transformations. During recovery or migration, preserve URLs and bytes for current manuscripts and past editions. Run the [integrity audit](../.github/workflows/audit-assets.yml) before retiring the old origin.
