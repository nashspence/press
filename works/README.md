# Works

This directory contains **working sources**, not automatically published editions.

For each work, create a folder named with a lowercase hyphenated slug, such as `works/example-essay/`. Copy the files from [templates/work/](../templates/work/) into it and replace the placeholders.

A suggested layout is:

```text
works/
  example-essay/
    README.md        # work metadata and draft status
    manuscript.md    # working source
    assets/          # optional figures or other supporting files
```

Commits and folders are always working history. For published editions, see the [catalog](../CATALOG.md) and [publication protocol](../PUBLICATION.md).
