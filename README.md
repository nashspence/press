# Press

An independent publishing imprint and public working archive for original written works by [nashspence](https://github.com/nashspence).

## Official editions

**Only a published, non-prerelease GitHub Release following [the publication protocol](PUBLICATION.md) is an official edition.** Commits, branches, tags alone, draft releases and prereleases are not. Each official edition designates a canonical attached artifact. GitHub's autogenerated source archives are snapshots of the whole repository, not the authoritative text of an individual work.

Consult the [catalog](CATALOG.md) for released works, and [PUBLICATION.md](PUBLICATION.md) for version/tag rules.

## Manuscripts and metadata

Each work is a `works/<slug>/manuscript.md` in strict **Pandoc/GFM Markdown with YAML front matter**. The [v2 source format](FORMAT.md) requires seven metadata fields and allows exactly two optional entries: `author_orcid` and an `identifiers` mapping with a fixed work-level namespace. Authoring remains readable; CI enforces schema, normalization, structure, math, links, and safe assets.

External identifiers assigned to **specific editions or formats**—including ISBNs, version DOIs, and library catalog numbers—do not belong in working manuscript front matter. Use the separately validated [registration index](REGISTRATIONS.md), where identities and qualifying serials have their own scopes. No external IDs have been assigned by this repository.

Start a work using [templates/work/](templates/work/) and review [works/README.md](works/README.md).

## Validation

[GitHub Actions](.github/workflows/validate-source.yml) checks all tracked sources on pushes and pull requests, including official-registration records. Tests are in [tests/](tests/) and validator code is in [scripts/](scripts/). [The release checker](.github/workflows/check-release.yml) runs **after** a release is published; neither workflow alone prevents a release or a direct change to `main`. Branch rulesets and pre-release enforcement are separate repository settings/processes.
