# Press

An independent publishing imprint and public working archive for original written works by [nashspence](https://github.com/nashspence).

## What is an official publication?

**Only a published, non-prerelease GitHub Release that follows [the publication protocol](PUBLICATION.md) is an official edition of this imprint.** Branches, commits, unassociated tags, draft releases, and prereleases are not official editions, even though some may be publicly accessible.

Each official edition identifies a *canonical attached artifact*. GitHub's autogenerated source archives are snapshots of the **whole repository**, not the authoritative text of any individual work.

See the [catalog](CATALOG.md) for released editions and [publication protocol](PUBLICATION.md) for the tag convention, release metadata, versioning, and publication procedure.

## Repository layout

- `works/<slug>/` — working manuscripts and supporting source materials.
- `templates/work/` — a starting point for new works.
- `RELEASE_NOTES_TEMPLATE.md` — metadata format for official releases.
- `.github/workflows/check-release.yml` — checks a release **after** it is published; it does not prevent invalid releases from being published.
- `COPYRIGHT.md` — default rights and permissions notice.

## Important distinction

The repository can be used for public drafting, but public availability may still count as prior publication for a journal, contest, publisher, or other third party. Keep works private elsewhere if first-publication eligibility or confidentiality matters.

## Source format and checks

The versioned, executable source contract is [FORMAT.md](FORMAT.md), implemented by [the validator](scripts/validate_sources.py) and [its regression tests](tests/test_validate_sources.py). Each work is self-contained: `manuscript.md` includes strict YAML front matter and the manuscript body; no separate metadata file is required. Use [the work template](templates/work/) to start.

[Source validation](.github/workflows/validate-source.yml) runs on every push and pull request. It checks tracked Markdown, work metadata, links, static assets, parser consistency, and generated HTML5/MathML. **It does not publish an edition or prevent merges until an active branch ruleset requires its passing check.**
