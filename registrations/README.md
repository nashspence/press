# Official external identifier registrations

This directory is for **verified, assigned identifiers** that are not inherently part of a manuscript's source revision. Nothing is registered yet. Do not add empty placeholders or fictitious numbers here.

Read [REGISTRATIONS.md](../REGISTRATIONS.md) for the exact validated locations, JSON schemas, check-digit rules, and distinction between work-level, edition-level, creator/publisher and serial identifiers. Official editions are designated exclusively through qualifying GitHub Releases as specified in [PUBLICATION.md](../PUBLICATION.md).
